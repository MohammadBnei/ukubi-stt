Persian needs to be selected — it is a separate model and auto-detect cannot reach it. Arabic and the European languages are auto-detected.

Record streams: 560ms chunks carrying a session id, decoded by a model that keeps its encoder state between them, so text appears about half a second behind you. Send a WAV goes as one offline decode against the batch model, which sees the whole utterance and is more accurate — streaming trades some of that for latency, and a file does not need the trade.
